# Changelog

## 1.0.0 — Initial public release

- Preliminary techno-economic assessment of hybrid CSP–CAES plants.
- Hourly operational optimization using PyPSA and HiGHS.
- Electricity trading and industrial process heat revenue assessment.
- Interactive Streamlit interface with configurable plant design parameters.
- Electricity market and solar resource datasets for ten geographical cases.
- Financial sensitivity analysis and scenario comparison.
- Standalone Python interface for detailed simulation and local result exports.
- Scientific documentation and input validation.
- Release of the source code under the MIT License.
